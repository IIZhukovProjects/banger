# Архитектура

| Компонент | Что делает |
| --- | --- |
| `frontend` | Раздаёт интерфейс общего экрана и контроллеров. |
| `backend` | Обслуживает `/api/`, хранит комнаты и игровые состояния в PostgreSQL, принимает загрузки и отправляет задания в AI Gateway. |

Публичный вход маршрутизирует `/` во frontend и `/api/` в backend. Браузер
передаёт код комнаты в `X-Room-Code`, а токен игрока в `Authorization` для
действий от его имени. Участники открывают комнаты по коду или по ссылке. Токен выдаётся при входе в комнату. Загрузка и выдача
изображений проходят через backend.

## Игровое состояние

Изменения комнаты сериализуются транзакцией PostgreSQL с блокировкой строки.
Ответы игроков скрыты от остальных до раскрытия. Правила раундов, голосования
и подсчёта очков находятся в `services/backend/src/game/`.

## Генерация изображений

Backend сохраняет запрос на генерацию вместе с игровым состоянием. Воркер
отправляет задание в AI Gateway со стабильным ключом идемпотентности, сохраняет
ID задания и опрашивает статус. Готовое изображение воркер скачивает в приватный
S3 Banger и регистрирует в комнате. Браузер получает файл через API Banger.

Спецификация API Banger лежит в `schemas/backend/api.yaml`.
